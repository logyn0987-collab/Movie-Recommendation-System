# Movie-Recommendation-System

-Project Description

A hybrid movie recommendation system that suggests personalized movies based on user preferences using collaborative filtering and content-based filtering techniques.

-Key Features
Collaborative Filtering (user-based recommendations)
Content-Based Filtering using TF-IDF
Dimensionality reduction using SVD
K-tuning optimization for model performance
Hybrid recommendation approach

-Technologies Used

Python, Pandas, Scikit-learn, TF-IDF, SVD, Surprise Library

-Outcome

Improved recommendation accuracy and provided personalized movie suggestions based on user behavior and movie metadata.
